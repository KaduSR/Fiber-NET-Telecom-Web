# Fiber NET Telecom Web

> Site institucional da Fiber NET Telecom — provedora de internet com mais de X anos de mercado.

## Sobre o Projeto

Modernizacao completa da presenca web da Fiber NET Telecom. O antigo site era estatico e nao 
conversava com as necessidades atuais de performance, SEO e conversao.

**Problema resolvido:** Site antigo com baixa performance, sem responsividade e sem captura de leads.

**Resultado:** Interface moderna com PageSpeed 95+, formulario de contato integrado e SEO otimizado.

## Stack

| Tecnologia | Versao | Uso |
|-----------|--------|-----|
| React | 18 | Interface |
| TypeScript | 5 | Tipagem |
| Tailwind CSS | 3 | Estilizacao |
| Vite | 5 | Build |
| Node.js | 20 | API |

## Funcionalidades

- Pagina inicial com apresentacao dos servicos
- Formulario de contato com validacao
- SEO on-page (meta tags, sitemap)
- Performance otimizada (Lighthouse 95+)
- Design responsivo (mobile-first)
- Deploy continuo

## Metricas de Impacto

| Metrica | Antes | Depois |
|---------|-------|--------|
| PageSpeed Mobile | ~55 | 95+ |
| PageSpeed Desktop | ~70 | 98+ |
| Leads via site | Nao havia | Captura ativa |

## Como Executar

```bash
git clone https://github.com/KaduSR/Fiber-NET-Telecom-Web
cd Fiber-NET-Telecom-Web
npm install
npm run dev
```
